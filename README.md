# Cathy-epg

## 1. Project

**Cathy-epg** publishes an XMLTV programme-metadata file assembled only from broadcaster websites and official TV-provider guides. It does not use EPGshare, epg.pw, IPTV playlists, third-party EPG mirrors, streams, account data, session cookies, or access-control bypasses.

The current XMLTV subscription is:

```text
https://raw.githubusercontent.com/waastudios/Cathy-epg/master/data/epg.xml.gz
```

`data/epg.xml.gz` is the compressed subscription file, `data/epg.xml` is its readable XMLTV counterpart, and `data/current_week.jsonl` is the normalised programme snapshot. Channel display names below are the official names published by the relevant provider; every listed XMLTV ID is taken from the current release.
